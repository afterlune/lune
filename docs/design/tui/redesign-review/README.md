# Lune TUI 原创布局候选稿

本目录包含三种新的 TUI 结构方向，每种一张主屏稿和一张状态稿。它们是布局评审图，不是实现规格；示例任务、文件名、阶段标签和快捷键可能与当前程序不符。选定方向后，所有文案和交互都映射到现有功能与 `keymap`。模型提问画面是未来功能的视觉草案，不表示该能力已经实现。

三种方向都取消右对齐用户消息和固定右侧 Activity/Usage 栏，保留会话、工具活动、权限审批、Plan、消息折叠、用量详情和窄屏退化等现有能力。

| 方向 | 主屏 | 状态稿 | 取舍 |
| --- | --- | --- | --- |
| 事件流 | [主屏](01-event-stream-main.png) | [空态、长消息、提问、详情](02-event-stream-states.png) | 消息和工具事件按时间进入单列，最贴近现有事件；工具较多时需要滚动。 |
| 任务工作台 | [主屏](03-task-workbench-main.png) | [空态、折叠/展开、审批、提问](04-task-workbench-states.png) | 阶段和证据更突出；Inspect/Plan/Act/Verify 不是当前 Core 状态，不能照图新增虚构状态，须映射已有事件或删去阶段语义。 |
| 会话工作区 | [主屏](05-session-workspace-main.png) | [空态、长消息、提问、详情、窄屏](06-session-workspace-states.png) | 会话导航常驻、活动详情从底部抽屉打开；窄屏时会话栏收起。 |

## 评审门禁

先选定一个结构方向，再逐项核对现有功能入口与窄屏表现；确认后才修改 `internal/tui/` 渲染实现。实现后更新确定性截图，并检查短/长输出、运行中工具活动和审批状态下布局是否稳定。旧版设计稿保留为历史材料，不覆盖。
