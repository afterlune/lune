# Lune TUI 原创布局候选稿

本目录包含三种新的 TUI 结构方向，每种一张主屏稿和一张状态稿。用户已选择并实现「会话工作区」；其余两种保留作设计记录。它们是布局评审图，不是实现规格；示例任务、文件名、阶段标签和快捷键可能与当前程序不符。选定方向后，所有文案和交互都映射到现有功能与 `keymap`。模型提问画面是未来功能的视觉草案，不表示该能力已经实现。

三种方向都取消右对齐用户消息和固定右侧 Activity/Usage 栏，保留会话、工具活动、权限审批、Plan、消息折叠、用量详情和窄屏退化等现有能力。

## 已实现方向

「会话工作区」已落地：左侧会话栏、中央事件时间线、底部 Activity/Usage 抽屉，窄屏时会话栏收起。示例任务、文件名和快捷键仍是概念稿占位，实际文案和操作映射到当前 `core.Session`、事件和 `keymap`；没有新增 Inspect/Plan/Act/Verify Core 状态。模型提问画面仍只是未来功能示意。

实现保留会话切换、归档/重命名/删除、权限审批、Plan、消息折叠、Activity 与 Usage 详情。确定性 SVG 截图已更新，覆盖短/长输出、抽屉滚动和窄屏。旧版设计稿和评审稿保留为历史材料，不覆盖。
