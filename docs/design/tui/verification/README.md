# TUI verification screenshots

These SVG snapshots are generated from deterministic Bubble Tea view fixtures by the session-workspace, transcript, fold-list, context settings, and compaction status snapshot tests.

The session-workspace matrix covers dark and light themes across empty, short output, long output, Activity/Usage drawer scroll top/bottom, persisted all-time per-agent usage, estimated context usage, narrow layouts, live streamed output with first-token latency, interrupted partial output, and resumed output alongside the preserved partial. A separate snapshot covers the optional Anime theme. The transcript matrix covers short messages, long collapsed and expanded messages, and narrow layouts in both themes. Image attachment snapshots cover the empty composer, one and multiple inline image tags, removed images, a 72-column layout, failed path loading, and the image limit in both themes. Fold-list snapshots show keyboard selection of arbitrary long messages, and context settings snapshots show project defaults and session override commands. SVGs preserve the rendered foreground colors and bold text, using the current ink/copper and warm-paper theme palettes for backgrounds and default text; inline image tags also preserve their accent backgrounds.

The short/long workspace pair keeps the left session rail fixed while the transcript grows. Tests also verify that drawer scrolling leaves the timeline and rail anchored, and that clicking a session restores it. Usage drawer snapshots include per-request agent/model attribution, persisted per-agent session totals, and grouped Team member activity. Compaction status snapshots capture in-progress and completed context compaction in both themes. Transcript assertions lock role-gutter alignment, regular-weight workspace chrome, plain message text, and long-message collapse thresholds. Stream tests cover batched live deltas, split line endings, partial Markdown/code fences, final-response reconciliation, model-call boundaries, agent/session filtering, and interrupted output labeling.

Snapshot paths resolve from the compiled test source when available and fall back to the working directory's module root for cross-compiled test binaries. The Anime fixture pins `NO_COLOR=1` so host color settings do not change the reference image; sprite rendering is covered by a separate unit test.

Refresh snapshots intentionally with:

`go test ./internal/tui -run 'TestTUI(SessionWorkspace|Conversation|ImageAttachmentComposer|FoldCommand|ContextCommand|AnimeTheme|CompactionStatus)SVGsMatchDeterministicFixtures' -args -update-tui-screenshots`
